# SpanishLine — Free subtitles & player for Language Transfer's Complete Spanish (Lessons 1–30)

Hand-proofread, timestamp-aligned Spanish **subtitles** plus a ready-to-use **offline player** for the first 30 lessons of Language Transfer's free Complete Spanish audio course. Study anywhere, on any device — no signup, no cost.

> Language Transfer's course is free but ships **without subtitles or a built-in player**, which is the single biggest blocker for self-learners. This project fixes that for Lessons 1–30, and shows you the upgrade path for the rest.

## How to use it

1. **Download the free pack** (link above) — Lessons 1–30 subtitles (`.srt`), hand-proofread and timestamp-aligned.
2. **Get the audio** — free and official from Language Transfer. See [AUDIO-SOURCES.md](AUDIO-SOURCES.md) for the one-click download link.
3. **Pair them up** — drop `Lesson NN.srt` next to the matching lesson audio; subtitles appear in any player (VLC, PotPlayer, Elmedia…). Or just open one of the `preview-mobile enhanced player/player-LNN.html` files — audio is already embedded, works offline.
